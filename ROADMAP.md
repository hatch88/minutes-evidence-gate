# Roadmap

The project starts with deterministic, local checks for quoted evidence in meeting action items.

## Next improvements

1. Report source line numbers for matching quotes.
2. Add machine-readable JSON output for use in CI and other pipelines.
3. Document Japanese-language meeting notes with fictional examples.
4. Improve diagnostics in response to real user reports.

Each change will be tracked by an issue or pull request and described in a release. The roadmap may change after users try the tool. No external adoption is claimed yet.
